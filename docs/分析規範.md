- 版本：2026-11-09
- 資料截止：2026-11-05（Global Fishing Watch 約有 72 小時延遲）
- 「近 30 天」一律指 2026-10-06 至 2026-11-05
- 時間：資料以 UTC 儲存；凡涉及「夜間」「時段」「季節」者，一律換算為台北時間（UTC+8）

## 1. 資料來源與基本單位

### 1.1 AIS 事件（Global Fishing Watch API v3）

本專案沒有逐點航跡，所有位置都來自 GFW 的「事件」。

| 事件 | GFW 資料集 | 用途 |
|---|---|---|
| 港口停靠 | port-visits | 母港、出港／回港時間、航次切分、停靠中國港口 |
| 海上滯留 | loitering | 海警船的主要位置來源，用於海域分布、夜間比例、編隊 |
| 作業 | fishing | 漁船作業位置與作業時數 |
| 相遇 | encounters | 與其他船靠近（漁船：與中國船相遇） |
| AIS 中斷 | gaps | GFW 判定的 AIS 關閉，含「疑似刻意關閉」旗標 |

每筆事件帶有 GFW 的區域標註。其中 `eez12Nm` 含中國（區域代碼 8486）者，視為「位於中國 12 浬內」。

### 1.2 分析對象與期間

**中國海警船**
- 納入條件：GFW 身分中，AIS 船名可解析出 4 位或 5 位舷號，且至少有 50 個位置點。
- 同一舷號的多個 MMSI 會合併成一艘船。
- 分析期間：2021-11-08 至 2026-11-05。

**科研／調查船**
- 依船名系列（向陽紅、實驗、海洋地質等）比對。
- 2021-11-08 之後的滯留事件用於編隊分析。

**台灣漁船**
- 抓取範圍：北緯 20–28 度、東經 116–126 度，船旗 TWN。
- 納入條件：至少有一筆作業事件，或 GFW 船型為漁船。
- 各類事件的期間：

  | 事件 | 期間 |
  |---|---|
  | 作業、滯留 | 2023-10 起（近三年） |
  | 港口停靠 | 2025-10 起 |
  | 相遇 | 2024-11 起 |
  | AIS 中斷 | 2025-10 起 |

- 重複事件以「類型、MMSI、開始時間、位置」去重。

### 1.3 舷號、單位與戰區

- 舷號、艦名、分局、直屬局／省局：來自維基百科（中、英）與海警定級表。
- 對應戰區按分局以地理對應，不代表指揮隸屬（海警隸屬武警）：

  | 分局 | 對應戰區 |
  |---|---|
  | 東海分局 | 東部戰區 |
  | 南海分局 | 南部戰區 |
  | 北海分局 | 北部戰區 |

## 2. 共用定義

| 名詞 | 定義 |
|---|---|
| 距離 | 以大圓公式計算（地球直徑 12,742 公里）。 |
| 夜間 | 台北時間 18:00 至隔日 05:59。滯留事件以其時間中點判定，出港以離港時間判定。 |
| 季節 | 春 3–5 月、夏 6–8 月、秋 9–11 月、冬 12–2 月，以台北時間的月份判定。 |
| 母港（推估） | 所有港口停靠中，累計停靠時數最多的港口。 |
| 航次（海警，一般分析） | 一次港口停靠結束，到下一次港口停靠開始；短於 0.25 天的不算。 |
| 航次（海警，案例分析） | 同上，但只取 2 小時至 60 天。 |
| 航次（漁船） | 同上，但只取 1 小時至 40 天。 |
| 百分位 | 某航次在該船過去航次中的位置，算法為（比它小的數量＋相同者的一半）÷基準數量×100。基準少於 6 趟不計算。 |
| 極端 | 百分位 ≥ 90 為「偏高」，≤ 10 為「偏低」。 |
| 平常少見 | 「是／否」類特徵在基準航次中出現比例 ≤ 20%（即稀有度 ≥ 80）。 |
| 嚴重度 | 3＝高、2＝中、1＝低。一艘船的異常分數為各項嚴重度加總。 |

## 3. 海域界定

本專案有四套海域劃分，各有用途：

- 3.1 海警「海域分類」：互斥，每點只歸一類
- 3.2 「重點海域」：可重疊
- 3.3 漁船「漁區」：互斥
- 3.4 圖台浬線

座標為（北緯, 東經）。

### 3.1 台灣本島與「距台灣距離」

- 以 16 個頂點的簡化多邊形代表台灣本島。點在多邊形內，距離為 0。
- 點在多邊形外時，計算該點到每條邊上 11 個等分點的最短距離。
- 換算：24 浬 ≈ 45 公里、80 浬 ≈ 150 公里、200 浬 ≈ 370 公里。
- 這是近似值，不是官方基線。

**海峽中線**
- 以北緯 27°／東經 122° 至北緯 23°／東經 118° 的直線段代表。
- 點到中線的距離以局部平面近似計算：東西向每度 111.32 公里×cos(緯度)，南北向每度 110.57 公里。

**其他與漁船相關的海域判定**
- **海域大類**（描述 AIS 關閉位置）：
  - 台灣周邊：北緯 18–30、東經 114–128
  - 北太平洋：北緯 ≥ 30、東經 100–180
  - 西太平洋：北緯 0–30、東經 100–180
  - 南太平洋或東太平洋：東經 > 100 或西經 > 100，依南、北半球區分
  - 印度洋：東經 20–100
  - 大西洋：其餘
- **漁場格網**：以 0.25 度為一格，記錄每艘船過去三年的作業格。「新作業海域」指距既有作業格 2 格（約 0.5 度）以上。
- **案例分析的中線相關特徵**：
  - 「接近中線」：距中線 ≤ 15 公里。
  - 「到達中線以西」：北緯 22.5–27.5、東經 < 122.5，且北緯 > 東經 − 95。

### 3.5 圖台浬線（3／6／9／12／24 浬）

- 由海岸線向外推算，海岸線包含台灣本島、澎湖、金門、馬祖、東沙與周邊小島。
- 作法：
  1. 投影到局部等距平面。
  2. 對陸地做緩衝區，1 浬 = 1,852 公尺。
  3. 扣除陸地本身。
- 這不是官方公告的領海基線，與法定 12 浬、24 浬範圍會有差異，僅供參考。

## 4. 中國海警船分析規則

### 4.1 勤務型態標籤（以 5 年資料計算）

| 標籤 | 條件 |
|---|---|
| 釣魚台巡弋型 | 在釣魚台滯留 ≥ 10 天 |
| 曾赴釣魚台 | 在釣魚台滯留 3–9 天 |
| 金馬海域型 | 金門＋馬祖滯留事件 ≥ 5 |
| 台灣周邊巡弋型 | 台灣相關海域（3.2 第 4–8 項中「台灣」開頭者、澎湖、東沙島）滯留事件 ≥ 10 |
| 南海爭議礁巡弋型 | 黃岩島＋仁愛礁／仙賓礁＋南沙（其他）滯留事件 ≥ 10 |
| 西沙巡弋型 | 西沙滯留事件 ≥ 10 |
| 夜間滯留偏多 | 滯留事件 ≥ 10，且夜間占比 ≥ 60% |
| 日間活動為主 | 滯留事件 ≥ 10，且夜間占比 ≤ 35% |
| 夜間出港偏多 | 航次 ≥ 10，且夜間出港占比 ≥ 50% |
| 長航程 | 單趟中位數 ≥ 7 天 |
| 近岸短程勤務 | 航次 ≥ 20，且單趟中位數 < 1 天 |
| 常關閉 AIS | GFW 判定 AIS 中斷累計 ≥ 500 小時 |
| AIS 資料稀少 | 滯留事件 < 3，且航次 < 3 |

### 4.2 季節分析

- **季節海域**：各季滯留事件依 3.2 分類計數，出現最多者為該季的主要海域。
- **季節性明顯**：事件數 ≥ 8 的季節中，主要海域不只一種。
- 另統計各季主要停靠港（依停靠時數）與各季航次數。

### 4.3 目前狀態（截至 2026-11-05）

| 狀態 | 條件 |
|---|---|
| 在港 | 最後一次港口停靠結束時間距資料截止 < 36 小時 |
| AIS 已停止發送 | 不符合「在港」，且最後一筆 AIS 早於資料截止前 3 天 |
| 在海上（推估） | 其餘情況；離港天數＝資料截止－最後離港時間 |

**母港總表**
- 「編制」為以該港為推估母港的船數。
- 「不明」對應「AIS 已停止發送」。

### 4.4 近 30 天異常規則

基準為 2026-10-06 之前的全部資料，近期為 2026-10-06 至 11-05。

| 異常 | 嚴重度 | 條件 |
|---|---|---|
| 新海域 | 高 | 基準滯留 ≥ 15 筆；近期在某海域（不含「其他」）滯留，而該海域在基準中占比為 0 |
| 少見海域 | 中 | 基準滯留 ≥ 15 筆；近期在某海域滯留 ≥ 2 次，且該海域在基準中占比 < 3% |
| 異常遠航 | 中 | 基準滯留 ≥ 15 筆；近期滯留點距母港超過「基準 95 百分位距離×1.15」，且超過 150 公里 |
| 時段改變 | 低 | 基準滯留 ≥ 15 筆、近期 ≥ 6 筆；夜間滯留占比與基準相差 ≥ 30 個百分點 |
| 活動激增 | 中 | 基準月均滯留 ≥ 2；近期滯留 ≥ 8 筆，且 ≥ 月均的 2.5 倍 |
| 活動驟減 | 低 | 基準月均滯留 ≥ 4；近期 0 筆，且 AIS 在近期仍有發送 |
| 新停靠港 | 中 | 基準停靠總時數 > 500 小時；近期停靠一個基準中從未停靠的港口 ≥ 6 小時，且距過去所有停靠點 > 30 公里 |
| 航程異常長 | 中 | 基準航次 ≥ 10；近期最長單趟（含目前仍在海上的天數）超過「基準 95 百分位×1.3」，且超過 3 天 |
| AIS 沉寂（高） | 高 | 航次 ≥ 10、最後 AIS 在 2026-03-01 之後；已沉寂 ≥ 14 天，且長於過去兩年最長的事件空窗 |
| AIS 沉寂（低） | 低 | 同上前提；沉寂 > 30 天，但過去兩年也曾有同等空窗 |
| 更換 MMSI | 中 | 近 60 天出現該舷號新的 AIS 身分 |

- 月均滯留＝基準滯留數 ÷ 基準期天數（至少 30 天）× 30。
- 「過去兩年最長事件空窗」以近期開始前 730 天內的港口與滯留事件時間計算。

### 4.5 編隊（共同滯留）

**兩艘海警船「共同滯留」的條件**
- 兩筆滯留事件的時間重疊；可放寬前後 3 小時。
- 兩者位置相距 ≤ 30 公里。

**統計方式**
- **夥伴船**：與某船共同滯留的天數排名（以台北時間日期計）。
- **編組**：同一天、同一海域（3.2 分類）出現共同滯留的所有舷號集合。
- **海警與科研船同行**：條件相同（時間重疊含前後 3 小時、30 公里內）。

共同滯留不等於確認的編隊，只代表時間與位置接近。

### 4.6 MMSI 切換

**候選**：A 身分的最後一筆事件之後，B 身分的第一筆事件須同時符合：
- 時間差在 −12 小時至 7 天之間。
- 兩點距離 ≤ 50 公里。
- 排除情況：
  - A 在資料截止前 7 天內仍有事件（尚未消失）。
  - B 在分析期開始後 3 天內就已存在（不是「新出現」）。
  - A 與 B 為同一 MMSI。

**強度**
- 「強」：時間差 ≤ 48 小時、距離 ≤ 10 公里，而且兩個身分的 AIS 期間正好在該時點前後 3 天內結束與開始。
- 「中」：其餘。

**分類**
- 同舷號換 MMSI，或不同舷號接手。
- 再依兩點是否都是港口停靠，分為「港內」或「海上」。
- 保留範圍：同舷號者、強度為「強」者，以及維基百科記載為「原舷號」改編者。
- 每個消失的身分只保留一個最佳配對，依序比較：強度、是否同舷號、時間差越短越好、距離越近越好。

## 5. 台灣漁船分析規則

- 基準：2026-10-06 之前的資料。
- 近期：2026-10-06 至 2026-11-05。
- 「作業事件」包含作業與滯留。

### 5.1 習慣總結

| 項目 | 規則 |
|---|---|
| 習慣漁區 | 近三年作業事件依 3.4 分類，取前 5 名與占比 |
| 各季作業習慣 | 該季事件 ≥ 5 才列出：主要漁區前 3、夜間占比、高峰時段（連續 3 小時事件最多者） |
| 歷年同期 | 每年 9/21–11/20 的主要漁區（2023、2024、2025 年） |
| 最活躍月份 | 事件最多的 3 個月份 |
| 日夜 | 夜間占比 ≥ 60% 為「多在夜間」，≤ 40% 為「多在白天」，其餘為「日夜都有」 |
| 漁具 | GFW 登記資料優先，標註「登記資料」；沒有登記資料時用 GFW 模型推估，標註「GFW 模型推估」 |
| 可能魚種 | 本專案依漁具、季節、夜間占比、漁區自行推估，每季最多 3 項；規則見 `tw_analyze.py` 的 `species_hint`，僅供參考 |

### 5.2 近 30 天異常規則

| 異常 | 嚴重度 | 條件 |
|---|---|---|
| 停靠中國港口 | 高或中 | 近期停靠中國港口（港口國籍為 CHN）。過去 12 個月從未停靠為「高」，否則為「中」 |
| 母港在中國 | 中 | 推估母港在中國，且近期停靠中國港口 |
| 進入中國 12 浬 | 高或低 | 近期有非港口事件位於中國 12 浬內。過去三年從未進入為「高」，否則為「低」 |
| 與中國船相遇 | 高 | 近期與船旗為中國，或 MMSI 開頭為 412／413／414 的船相遇；若對方是本專案清冊中的海警或科研船，會標示舷號或船名 |
| 新作業海域 | 中 | 基準作業 ≥ 20 筆；近期作業點距既有作業格 2 格（約 0.5 度）以上 |
| 異常遠離母港 | 中 | 近期作業點距母港超過「95 百分位距離×1.2」，且 > 60 公里。95 百分位優先用歷年同期（≥ 20 筆），不足時改用近三年全部 |
| GFW 判定關閉 AIS | 高、中或低 | 2025-10 之後、GFW 標記「疑似刻意關閉」，且推算航速 ≤ 15 節的中斷。過去 12 個月少於 3 次時：關閉或恢復點在台灣周邊為「高」，否則為「中」。已 ≥ 3 次則為「低」（屬常態） |
| 出港後失聯 | 中 | 前提：過去出港後間隔 ≥ 20 次、80% 以上作業在 3.4 的命名漁區內、不是浮標（船名不含 % 或 BUOY）、基準作業 ≥ 20 筆。門檻＝max（72 小時、過去出港後間隔 95 百分位×3、過去最長間隔×1.5）。近期出港後到下一筆事件超過門檻；或最後一筆是出港且至今超過門檻 |
| 偏離同季節漁區 | 高或中 | 近期作業 ≥ 5 筆，且主要漁區占近期 ≥ 40%；歷年同期作業 ≥ 15 筆、涵蓋 ≥ 2 年；該漁區在歷年同期占比 < 10%。若為敏感漁區（中國沿岸 12 浬內、金門／廈門灣、福建近海、釣魚台海域）且過去三年從未去過，為「高」 |
| 作業漁區改變（無同期資料） | 高或低 | 同期資料不足時：基準作業 ≥ 20 筆，主要漁區在過去三年占比 < 10%，且不是任何一年同期的主要漁區。敏感漁區且從未去過為「高」，否則為「低」 |
| 日夜作業型態改變 | 低 | 近期作業 ≥ 10 筆、歷年同期 ≥ 15 筆；夜間占比與歷年同期相差 ≥ 35 個百分點 |

**關於歷年同期**
- 漁船作業有季節性，所以漁區和日夜比較以「歷年同期」（每年 9/21–11/20）為基準，而不是全年平均。
- 這樣才能分辨「換季移動」與「真的偏離」。

## 6. 案例特徵分數（風險分數）

兩類船使用同一套方法：

1. 以公開報導的真實案例為「案例」。
2. 找出案例船在事件當時的航次，和該船自己過去的航次比較。
3. 以一般航次為對照，找出在案例中明顯較常出現的特徵。
4. 以 ln（倍數）為權重，替現有船隻計分。

### 6.1 共同計算方式

| 項目 | 定義 |
|---|---|
| 案例比例 | 案例中符合該特徵的比例 |
| 對照比例 | 對照中符合該特徵的比例 |
| 倍數 | 案例比例 ÷（對照比例 + 0.01）；加 0.01 是避免對照為 0 時倍數無限大 |
| p 值 | 單尾 Fisher 精確檢定（超幾何分布），檢驗案例比例是否顯著高於對照 |
| 權重 | ln（倍數），取到小數第二位 |
| 分數 | 一個航次符合的所有已採用特徵的權重加總。期間型特徵（近 90 天變化）以船為單位判定；一艘船若有多個近期航次，取最高分的航次 |

## 7. 即時告警（每 6 小時）

**運作方式**
- 由 `job/daily.py` 執行，每 6 小時抓取最近 10 天的港口停靠與滯留事件。
- 與 `job/baseline.json` 的各船常態比較。
- 同一艘船、同一類告警只保留最高嚴重度的一筆。

| 告警 | 嚴重度 | 條件 |
|---|---|---|
| 新海域 | 高 | 該船過去滯留 ≥ 15 筆；在過去占比為 0 的海域（3.2 分類，不含「其他」）滯留 |
| 少見海域 | 中 | 同上，但過去占比 < 3% |
| 異常遠航 | 中 | 距母港超過 max（150 公里、過去 95 百分位×1.15） |
| 進入重點海域 | 中或低 | 滯留點落在台灣相關重點海域（台灣東部、海峽中線、中線以東、金門、馬祖、澎湖、台灣西南、東沙）或釣魚台。過去 5 年未曾出現為「中」，否則為「低」 |
| 科研船同行 | 中 | 與科研／調查船的滯留事件開始時間相差 < 12 小時，且相距 ≤ 30 公里 |
| 出港時段異常 | 低 | 過去航次 ≥ 20；出港時刻（台北時間）前後 1 小時都不在過去常用時段內（常用時段＝占出港 ≥ 3% 的小時） |
| AIS 沉寂 | 高 | 過去航次 ≥ 10；最後事件距今超過 max（14 天、過去兩年最長事件空窗） |
| 群體出港 | 中 | 同一母港 3 小時內有 ≥ 3 艘出港 |

**目前動態**
- 在港：最後一次港口停靠結束距最新資料 < 36 小時。
- 出航：其餘。

**公開版（GitHub Pages）**

|---|---|

## 9. 限制與解讀原則

1. **只看得到 AIS 有開的航段。** 船隻關閉 AIS、未裝設 AIS，或使用他船身分時，本專案無法偵測其行為。
2. **位置來自事件，不是逐點航跡。** 滯留、作業、相遇、停靠事件之間的航線是推估的。
3. **GFW 約有 72 小時延遲**，即時查緝需搭配雷達、岸台 AIS 與衛星合成孔徑雷達。
4. **所有異常與分數都是「線索」，不是判定。** 多數異常有正常原因，例如換季、換漁法、避風、維修、設備故障、執行例行勤務。
5. **案例數很少。** 漁船案例只有 13 艘，海警事件雖有 176 船次，但事件航次與平常差異小。特徵權重會隨案例增加而改變，應定期重算。
6. **季節偏差。** 漁船對照組在 7 月評估，現有漁船在 11 月評估，換季可能使「近 90 天」類特徵的符合數偏高。
7. **身分比對可能出錯。** 船名對 MMSI、舷號對 MMSI 都可能有誤，例如同名船、改名、報導舷號錯誤。
8. **共同滯留不等於編隊，MMSI 切換候選不等於確認。** 時間與位置接近只是必要條件，不是充分條件。
9. **漁區、重點海域與浬線都是研究用的近似劃分**，不是官方公告的界線。
